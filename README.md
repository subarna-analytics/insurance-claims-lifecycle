# Insurance Claims Lifecycle

## Overview

This repository documents the end-to-end claims lifecycle in a typical insurance system.

---

## Stages

### 1. FNOL (First Notification of Loss)

* Claim is registered
* Basic details captured

### 2. Validation

* Policy check
* Coverage validation
* Fraud indicators

### 3. Assessment

* Loss evaluation
* Adjuster involvement

### 4. Decision

* Approve / Reject / Investigate

### 5. Settlement

* Payment processing
* Closure

---

## Observations

* Validation stage is a bottleneck
* High dependency on manual checks
* Opportunity for automation

---

## Future Enhancements

* Rule-based validation engine
* AI-assisted fraud detection
* API integration with third-party data sources
